## 🚀 Projeto em destaque

### [fastapi-py](https://github.com/ghsantos-software/fastapi-py) &nbsp;·&nbsp; [demo ao vivo ↗](https://fastapi-py-ptd6.onrender.com/docs)

API REST de usuários e pedidos com pipeline de entrega de ponta a ponta — do pull request à produção em um único merge.

- **CI/CD completo** — cada pull request roda lint, suíte de testes com cobertura e as migrações do banco; cada merge na `main` publica a imagem no GitHub Container Registry e dispara o deploy automático.
- **PostgreSQL** com migrações versionadas (Alembic), aplicadas na subida do container; um check de CI garante que modelos e migrações nunca ficam fora de sincronia.
- **Infraestrutura como código** — Terraform descreve a stack AWS (ECR, EC2, IAM), formatado e validado no CI.
- **`main` protegida** — nada entra sem pull request com todos os checks verdes.
- **Automação de dependências e segurança** — Dependabot, SonarCloud e GitGuardian em cada pull request.

<sub>`FastAPI` · `PostgreSQL` · `Docker` · `GitHub Actions` · `Terraform` · `Pytest` · `Render` · `Neon`</sub>
